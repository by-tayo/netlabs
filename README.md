# NetLabs - Networking Notes & Hands-on Labs

A personal networking knowledge base documenting network protocols, infrastructure, configurations, packet analysis, and troubleshooting through structured notes and practical labs.

This repository serves as a hands-on learning environment for exploring how networks operate, how devices communicate, and how networking technologies are applied in real-world environments.

## Objectives

- Develop a strong understanding of networking fundamentals.
- Document network protocols, ports, and communication standards.
- Explore network configurations and infrastructure.
- Practice packet analysis and network troubleshooting.
- Gain hands-on experience with networking and diagnostic tools.
- Apply theoretical knowledge through practical labs and projects.

## Topics Covered

| Area | Topics |
|---|---|
| Networking Fundamentals | OSI model, TCP/IP, encapsulation, network topologies |
| Protocols & Ports | TCP, UDP, SMTP, POP3, IMAP, DNS, DHCP |
| Network Infrastructure | Routers, switches, wireless access points, firewalls |
| Network Operations | Monitoring, configuration, performance, documentation |
| Network Security | ACLs, segmentation, secure protocols, firewall rules |
| Troubleshooting | Connectivity, latency, packet loss, DNS, routing |

## Tools & Technologies

Tools used throughout this repository:

- **Wireshark** - Packet capture and network protocol analysis.
- **Nmap** - Network discovery and port scanning.
- **Cisco Packet Tracer** - Network simulation and configuration.
- **PowerShell** - Windows networking and troubleshooting.
- **Linux** - Network administration and diagnostic commands.
- **Traceroute / Ping** - Connectivity and routing diagnostics.
- **Netstat / SS** - Connection and listening-port inspection.

## Hands-on Labs

Each lab will include:

1. **Objective** - What I am trying to learn.
2. **Environment** - Tools, operating systems, and configurations.
3. **Implementation** - Commands and procedures performed.
4. **Observations** - What happened and why.
5. **Troubleshooting** - Issues encountered and how they were resolved.
6. **Key Takeaways** - What I learned and its real-world application.
